# Open Archive of Mathematics and Formal Philosophy
As stated in the description, this is an open access library for the foundations and philosophy of mathematics*. (And theoretical computer science. If you don't like that, blame Curry and Howard.)
---
## Guidelines
Submissions can be made via the curator's email address, and should have the subject line "Archive submission"; files must be attached in either Markdown or LaTeX. All applicable metadata must be supplied.
